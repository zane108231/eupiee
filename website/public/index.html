FAQ

Good to know.

How do I add Euphie to my server?+

Pick an Euphie from the crew above, select your server in Discord's authorization screen, and approve the permissions. You'll need the Manage Server permission.

How do I start playing music?+

Join a voice channel and use e!play followed by a song or playlist. Run e!help in Discord for the full command list.

Why would I want more than one Euphie?+

Each Euphie is a separate bot account — up to six voice channels can play music at once, and if one is busy the next one steps in automatically.

Do the bots share a queue?+

Each bot manages its own session in its voice channel, while the crew coordinates so there's always an Euphie ready to play.

Is Euphie Music free?+

Yes — inviting and using the bots is free. Support the project through the support server if you'd like.
